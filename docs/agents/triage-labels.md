# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Work is waiting for more information |
| `ready-for-agent` | `ready-for-agent` | The issue is specific enough for an agent to implement |
| `ready-for-human` | `ready-for-human` | The issue requires human action or judgment |
| `wontfix` | `wontfix` | The repository will not act on the issue |

When a skill names a canonical triage role, apply the matching GitHub label from this table.
